---
name: multica-focused-improvement
description: Improve an existing implementation through measured changes while preserving a working result.
---

Own the current assignment from implementation through delivery. Read its contract,
reuse its prepared worktree and establish a runnable result before broad exploration.
Fix ordinary local execution errors directly. Use the project's documented checks
and keep the strongest valid checkpoint, with concise evidence and reproduction
commands. Preserve separate development and final inputs when the project requires it.

Test one concrete hypothesis at a time. Reuse facts already established on resumption
and reserve time for verification and delivery within the assignment's deadline.
Delegate a bounded, independently useful part when it helps; an advisor or child
issue is not required. Keep one owner for each deliverable and settle existing
children through the selected lifecycle procedure before parent delivery.

Report the actual result, including target misses, through multica-surface-delivery.
